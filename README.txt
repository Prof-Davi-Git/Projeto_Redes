COMO USAR
1. Abra a pasta no VS Code.
2. Não precisa instalar nenhuma extensão.
3. Abra o arquivo index.html no navegador (dois cliques pelo Explorador do Windows).
4. O site funciona sem servidor e sem banco de dados.

PARA OS ALUNOS
- Não precisam editar HTML, CSS ou JavaScript.
- Eles trabalham dentro do próprio site.
- No fim da aula clicam em "Salvar projeto".
- Será baixado um arquivo JSON, por exemplo: Rede_ByteTech.json.
- Esse JSON deve ser salvo na pasta do grupo no Google Drive.
- Na aula seguinte: abrir index.html > "Abrir projeto" > selecionar o JSON.

JÁ FUNCIONA
- Nome, grupo, integrantes e descrição da empresa.
- Criação de departamentos.
- Equipamentos: computador, notebook, switch, roteador, servidor, impressora e access point.
- Arrastar equipamentos no mapa.
- Conectar equipamentos visualmente.
- Dois cliques para editar equipamento.
- Cadastro de IP, prefixo, MAC, departamento, status e observações.
- Tabela automática de endereçamento.
- Histórico de alterações.
- Dashboard.
- Salvar e abrir projeto em JSON.

SUGESTÃO
Use o mesmo site para toda a turma. Cada grupo mantém apenas o seu arquivo JSON.
